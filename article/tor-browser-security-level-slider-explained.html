Tor Browser Security Level Slider Explained

The Tor Browser security level slider is a built-in privacy and security feature that allows users to increase their protection against digital threats by disabling specific website functions that are vulnerable to exploitation. By adjusting this slider, users can customize the trade-off between web page usability and advanced defense against malware, tracking, and browser vulnerabilities.

Where to Find the Security Slider

The security slider is represented by a shield icon located to the right of the address bar in Tor Browser. Clicking this shield allows you to view your current security status and access the security settings to adjust the slider according to your needs.

The Three Security Levels

Tor Browser provides three distinct security tiers:

  • Standard (Default): In this mode, all Tor Browser and standard website features are enabled. It provides standard Tor anonymity protections without breaking regular website functions, audio, video, or interactive scripts.
  • Safer: This level disables website features that are frequently used to launch cyberattacks or deanonymize users.
    • JavaScript is automatically disabled on all non-HTTPS websites.
    • Some fonts and mathematical symbols are disabled.
    • Audio and video (HTML5 media) become click-to-play rather than playing automatically.
  • Safest: This tier provides the highest level of security and only allows web features necessary for static sites and basic services.
    • JavaScript is disabled by default across all websites.
    • Some fonts, icons, and mathematical symbols are disabled.
    • HTML5 media elements are click-to-play.
    • Many modern, interactive websites may fail to render or function properly.

Choosing the Right Level

  • Use Standard if you need regular web browsing where modern web applications, streaming video, and interactive forms work seamlessly.
  • Use Safer if you want stronger protection against network adversaries and malicious scripts while maintaining usability on most HTTPS-encrypted websites.
  • Use Safest if you are operating in a high-threat environment, accessing sensitive information, or want maximum defense against zero-day browser exploits at the cost of website interactivity.
